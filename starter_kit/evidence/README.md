# LoomQ 人工评分证据

这份文件是人工评分材料的统一入口。请直接编辑它，只填写要申报的项目。截图、原始结果或图表统一放在 `starter_kit/evidence/files/`，也可以引用 `starter_kit/` 中已有的代码和文档。

证据包是可选的。没有申报某项人工分时，留空即可，不影响自动评分。

## 提交前填写

把要申报项目的方框改成 `[x]`，并填写对应内容：

- [x] L1 真机
- [x] L2 交互体验
- [x] 工程与产品化
- [ ] 自定义量子 RISC-V Bonus
- [ ] 新手引导与视觉叙事 Bonus

## L1 真机

每个有效真机平台计 5 分，最多两个平台。模拟器不计真机分。每个平台复制并填写一次下面的信息：

```text
平台名称：量旋云（SpinQ Cloud）—— triangulum_vp 3比特核磁量子计算机
平台 job ID：S-260812-0004
运行时间：2026-08-12T07:35:16Z（UTC）
shots：2048
实际执行的 QASM：evidence/files/spinq-ghz3-circuit.qasm
平台返回的原始结果：evidence/files/spinq-ghz3-result.json
任务页截图：无（job ID 可在量旋云控制台「实验任务」按 S-260812-0004 溯源）
主峰命中：000 (899) + 111 (907) = 88.2%，与 GHZ-3 理想主导态一致
```

建议把文件放进 `evidence/files/`，比如：

```text
evidence/files/spinq-circuit.qasm
evidence/files/spinq-result.json
evidence/files/spinq-screenshot.png
```

工作人员会核对 job ID、运行时间、电路、shots 和原始结果。截图只能辅助说明，不能代替 job ID 和原始结果。

## L2 交互体验

请填写：

```text
启动界面或 CLI 的命令：python web_agent.py --host 0.0.0.0 --port 8787
测试入口或页面地址：http://<host>:8787/ （浏览器打开，本地为 http://127.0.0.1:8787/）
适合现场体验的 3 个用户任务：
1. 自然语言生成：点击示例按钮"生成 3 比特 GHZ 态"，或直接输入"生成一个 3 比特的最大纠缠态（GHZ 态），并进行全测量"——助手写出 QASM 并通过自研模拟器实时跑出测量分布柱状图。
2. 代码纠错：点击示例按钮"修复报错的贝尔态代码"（H q[0]; CX q[0] q[1]）——助手识别未定义寄存器与门名大小写错误，给出可运行的贝尔态程序并可视化 00/11 各半的结果。
3. 智能选后端：点击示例按钮"为 15 比特电路选后端"，或输入"我需要运行一个 15 比特电路，且零排队等待，选哪个平台？"——助手依据官方后端能力表推荐规范后端标识（如 braket_local_simulator）。
截图或演示视频：[选填，填写仓库内路径或稳定只读链接]
```

工作人员会在组委会统一模型环境中运行最终代码，测试新手是否看得懂、出错后能否得到有效帮助、结果是否清楚，以及多轮回答是否一致。选手自己的对话截图只用于说明产品流程，不直接证明得分。

界面说明：`web_agent.py` 是零第三方依赖的单文件 Web 控制台（仅用 Python 标准库 `http.server`），采用"实验室控制台"风格——顶部仪表状态栏（LED 指示模型服务就绪状态）、示例任务芯片、聊天区、测量结果柱状图。AI 回复中的 QASM 会被高亮渲染，并自动调用 L1 自研模拟器运行 8192 次采样做结果可视化；未配置 `LOOMQ_LLM_*` 时页面会明确提示，后端推荐任务（基于本地能力表）仍可离线工作。

## 提交规则

- 所有材料都要在截止前进入最终提交的 commit，工作人员不接受截止后补交。
- 外部视频可以用稳定只读链接，源码、原始结果和复现命令应保存在仓库中。
- 整个 fork commit 的归档包不得超过 100 MiB。
- 不要提交 API Key、Token、Cookie、个人身份信息或平台账户隐私。
- 如申报 L1 真机分，在最终提交 Issue 的 `Hardware evidence` 中填写 `starter_kit/evidence/README.md`。
